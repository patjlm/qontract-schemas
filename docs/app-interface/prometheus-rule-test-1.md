# App Interface Prometheus Rule Test

**Schema location:** [/app-interface/prometheus-rule-test-1.yml](/schemas/app-interface/prometheus-rule-test-1.yml)

**Description:** Schema for defining Prometheus rule tests in app-interface. 
This includes configurations for rule files, evaluation intervals, 
test cases, and expected outputs.


| Name | Type | Required | Possible Values | Description |
|---|---|---|---|---|
| $schema | string | yes | /app-interface/prometheus-rule-test-1.yml |  |
| rule_files | array | yes |  | A list of Prometheus rule files to be tested. |
| evaluation_interval | string | no |  | The interval at which Prometheus evaluates the rules. |
| group_eval_order | array | no |  | The order in which rule groups are evaluated. |
| tests | array of [tests](#array-tests) | yes |  | A list of test cases for Prometheus rules. |
